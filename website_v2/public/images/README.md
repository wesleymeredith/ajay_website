# Images

Put photos here, then reference them from `data/profile.ts` or `data/projects.ts`.

Examples:

- Profile photo: `public/images/avatar.jpg` → `avatar: "/images/avatar.jpg"`
- Project screenshot: `public/images/projects/lab-1.png` → `images: ["/images/projects/lab-1.png"]`

Paths always start with `/images/` because the `public/` folder is the website root for static files.

Keep screenshots reasonably small (under ~500KB) so the site stays fast.
